# FlowNote 部署与安装说明

> **版本**：v1.2-MVP  
> **更新日期**：2026-07-03  
> **适用对象**：开发者、运维人员

---

## 一、系统概述

FlowNote 采用 **前后端分离 + 容器化部署** 架构：

```
浏览器 ──→ Nuxt 3 前端 (:3001) ──→ Hono API (:3000) ──→ PostgreSQL (:5432)
```

| 组件 | 技术 | 端口 |
|------|------|------|
| 前端 | Nuxt 3 + Vue 3 + TypeScript | 3001 |
| 后端 API | Hono + Drizzle ORM + TypeScript | 3000 |
| 数据库 | PostgreSQL 16 Alpine | 5432 |
| 反向代理 | Nginx（生产环境可选） | 80/443 |

---

## 二、环境要求

| 依赖 | 最低版本 | 用途 |
|------|---------|------|
| Node.js | 22+ | 运行前端/后端开发服务 |

| Docker Desktop | 24+ | 运行 PostgreSQL 容器 |
| Git | 2.30+ | 代码拉取 |

## 三、快速安装（推荐）

### 3.1 一键安装（Windows）

双击项目根目录下的 `setup.bat`，脚本自动完成：

1. 检查 Node.js 22+、pnpm、Docker Desktop
2. 安装项目依赖
3. 创建 `.env` 配置文件
4. 启动 PostgreSQL 容器
5. 初始化数据库
6. 启动开发服务器

### 3.2 一键安装（Linux / macOS）

```bash
chmod +x setup.sh
./setup.sh
```

## 四、手动安装

### 步骤 1：克隆代码

```bash
git clone https://github.com/csx755/SE-flownote.git
cd SE-flownote
```

### 步骤 2：安装依赖

```bash
pnpm install
```

> 若提示 "Ignored build scripts"，执行 `pnpm approve-builds`，选中 `esbuild`、`@parcel/watcher`、`vue-demi` 后回车，再 `pnpm install`。

### 步骤 3：配置环境变量

```bash
cp .env.example apps/api/.env
```

编辑 `apps/api/.env`，修改以下配置：

```env
DATABASE_URL=postgresql://flownote:flownote@localhost:5432/flownote
JWT_SECRET=你的随机密钥（至少16位）  # ⚠️ 必须修改！
PORT=3000
```

> JWT_SECRET 不要使用 `your-secret-key-here` 或 `change-me-in-production`，代码会拒绝这些占位值。

### 步骤 4：启动 PostgreSQL

```bash
docker compose up -d postgres
```

验证：`docker ps` 中应看到 `flownote-db` 状态为 `(healthy)`。

### 步骤 5：初始化数据库

```bash
pnpm db:push
```

首次运行输出 `[✓] Changes applied`，后续输出 `[i] No changes detected`。

### 步骤 6：启动服务

**同时启动 API + 前端（推荐）：**

```bash
pnpm dev
```

**分别启动：**

```bash
# 终端 1：API
pnpm --filter @flownote/api dev

# 终端 2：前端
pnpm --filter @flownote/web dev
```

### 步骤 7：验证

| 检查项 | 操作 | 预期结果 |
|--------|------|----------|
| API 健康检查 | `curl http://localhost:3000/health` | `{"status":"ok"}` |
| API 文档 | 浏览器打开 `http://localhost:3000/docs` | Scalar API 文档页面 |
| 前端页面 | 浏览器打开 `http://localhost:3001` | FlowNote 首页 |

## 五、Docker Compose 部署（纯容器化）

适合生产环境或不安装 Node.js 的场景。

```bash
# 1. 配置 .env（同上步骤 3）
cp .env.example apps/api/.env
vim apps/api/.env

# 2. 构建并启动所有容器
docker compose up -d --build

# 3. 初始化数据库
pnpm db:push

# 4. 访问
# API: http://localhost:3000
# （前端需单独启动或改用 Nginx 托管静态文件）
```

容器清单：

| 容器名 | 镜像 | 端口 |
|--------|------|------|
| `flownote-db` | postgres:16-alpine | 5432 |
| `flownote-api` | notebook-api (自构建) | 3000 |

## 六、生产环境部署

### 6.1 服务器要求

- Linux 服务器（Ubuntu 22.04 推荐）
- 2 核 CPU、2 GB 内存（最低）
- 20 GB 磁盘
- 公网 IP 或域名

### 6.2 部署步骤

```bash
# 1. 安装 Docker
curl -fsSL https://get.docker.com | sh

# 2. 克隆代码
git clone https://github.com/csx755/SE-flownote.git /opt/flownote
cd /opt/flownote

# 3. 配置
cp .env.example apps/api/.env
# 编辑 apps/api/.env:
#   JWT_SECRET=生产随机密钥
#   DATABASE_URL=postgresql://flownote:生产密码@postgres:5432/flownote

# 4. 修改 docker-compose.yml 中 postgres 密码

# 5. 启动
docker compose up -d --build

# 6. 初始化数据库
docker exec flownote-api node dist/db-push.js
```

### 6.3 Nginx 反向代理（推荐）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /opt/flownote/apps/web/.output/public;
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 6.4 HTTPS 证书（Let's Encrypt）

```bash
apt install certbot python3-certbot-nginx
certbot --nginx -d your-domain.com
```

## 七、数据库管理

### 查看数据（命令行）

```bash
docker exec -it flownote-db psql -U flownote -d flownote
```

常用 SQL：

```sql
SELECT * FROM users;           -- 查看用户
SELECT * FROM notes;           -- 查看便签
SELECT * FROM knowledge_pages; -- 查看知识页
SELECT * FROM tasks;           -- 查看任务
```

### 图形化工具

```bash
pnpm db:studio
# 打开 https://local.drizzle.studio
```

### 备份与恢复

```bash
# 备份
docker exec flownote-db pg_dump -U flownote flownote > backup.sql

# 恢复
docker exec -i flownote-db psql -U flownote flownote < backup.sql
```

## 九、常见问题

### Q1：`EADDRINUSE` 端口 3000 被占用

```bash
npx kill-port 3000
```

### Q2：`ECONNREFUSED` 连接 PostgreSQL 失败

Docker Desktop 未启动或 PostgreSQL 容器未运行：

```bash
docker ps | grep flownote-db
# 如果没有，启动它：
docker compose up -d postgres
```

### Q3：数据库初始化报错

确保 `.env` 中 `DATABASE_URL` 格式正确：

```
postgresql://用户名:密码@主机:端口/数据库名
```

### Q4：pnpm install 失败

清除缓存重试：

```bash
rm -rf node_modules pnpm-lock.yaml
pnpm install
```

### Q5：Windows 上 Docker 无法启动

1. 确认开启了 BIOS 虚拟化（VT-x/AMD-V）
2. 确认安装了 WSL2：`wsl --install`
3. 重启 Docker Desktop
