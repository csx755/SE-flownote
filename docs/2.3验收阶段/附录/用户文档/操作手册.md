## 一、产品简介

FlowNote（流知）是一个将**碎片信息捕获 → 知识结构化 → 任务执行**串联起来的生产力工具。

**核心工作流：**

```
📝 便签捕获 ──→ 📄 知识页面结构化 ──→ ✅ 任务看板执行
   碎片想法         整理成体系           落地为行动
```

---

## 二、快速入门

### 2.1 注册与登录

1. 浏览器打开 `http://localhost:3001`
2. 首次使用点击 **"注册"**，填写用户名、邮箱、密码
3. 注册成功后自动登录
4. 后续访问直接登录即可

> 密码最低 8 位，邮箱格式需合法。

### 2.2 首页导航

登录后顶部导航栏提供：

| 入口 | 功能 |
|------|------|
| 📝 便签 | 碎片信息快速记录 |
| 📄 知识页面 | 结构化文档编辑 |
| ✅ 任务看板 | 任务管理与追踪 |
| 🔍 搜索 | 全局内容搜索 |

## 三、便签模块

> 路径：`http://localhost:3001/notes`

便签是最轻量的信息捕获入口，适合记录一闪而过的想法、待办清单、会议记录等。

### 3.1 创建便签

在顶部输入框输入内容，按 **`Ctrl + Enter`** 或点击 **"创建便签"** 按钮。

### 3.2 编辑便签

- 点击便签卡片进入编辑模式
- **`Ctrl + Enter`**：保存
- **`Esc`**：取消编辑

### 3.3 便签操作

| 按钮 | 功能 |
|------|------|
| ✏️ | 编辑便签内容 |
| 📄 | 转为知识页面（标题取第一行） |
| ✅ | 转为任务（标题取第一行） |
| 📦 | 归档（隐藏到已归档列表） |
| 🗑️ | 删除（不可恢复） |

### 3.4 便签时间线

便签按日期自动分组：
- **今天**：当日创建的便签
- **昨天**：昨日创建的便签
- **更早**：更早的便签

### 3.5 归档管理

- 点击 **"已归档"** 标签查看归档便签
- 点击 **↩️** 恢复归档便签到活跃列表

## 四、知识页面模块

> 路径：`http://localhost:3001/pages`

知识页面是将碎片信息整理为结构化文档的空间，支持完整的 Markdown 编辑。

### 4.1 页面列表

列表页以卡片形式展示所有知识页面：
- 鼠标悬停显示绿色边框
- 点击卡片进入编辑
- 每张卡片显示标题、内容预览、更新时间

### 4.2 文件夹管理

左侧文件夹侧栏支持层级组织：

- **树形结构**：支持 `工作/项目A` 格式的子目录
- **点击文件夹**：筛选该文件夹下的页面
- **▶ / ▼**：展开/折叠子文件夹
- **移动页面**：每张卡片下拉框可选择目标文件夹，选 "+ 新建文件夹..." 可输入新路径

### 4.3 创建页面

点击 **"新建页面"**：
1. 输入页面标题
2. 可选填文件夹路径（如 `工作/项目A`）
3. 点击 **"创建"**

### 4.4 Markdown 编辑器

知识页面使用 CodeMirror 6 编辑器，支持以下功能：

**工具栏按钮：**

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| **B** | 加粗 | `Ctrl + B` |
| *I* | 斜体 | `Ctrl + I` |
| ~~S~~ | 删除线 | — |
| <u>U</u> | 下划线 | — |
| `</>` | 行内代码 | — |
| H1 H2 H3 | 标题 1/2/3 | — |
| • | 无序列表 | — |
| 1. | 有序列表 | — |
| > | 引用 | — |
| ``` | 代码块 | — |
| 🔗 | 链接 | — |
| ☐ | 任务列表 | — |
| — | 分割线 | — |
| ⊞ | 表格 | — |

**语法支持：**
- 标准 Markdown（标题、列表、链接、图片、代码等）
- `**加粗**` `*斜体*` `~~删除线~~`
- `==高亮==`（荧光笔效果）
- 表格、分割线、任务列表 `- [ ]`

**实时预览：**
编辑器右侧同步显示渲染后的内容，所见即所得。

### 4.5 页面操作

编辑页面底部操作栏：

| 按钮 | 功能 |
|------|------|
| ← 返回知识页列表 | 回到列表页 |
| 转为任务 | 将当前页面转换为任务 |
| 导出 .md | 下载为 Markdown 文件 |
| 导出 .txt | 下载为纯文本文件 |
| 保存 | 保存修改（`Ctrl + S`） |

### 4.6 反向链接

打开知识页面时，系统自动检测其他页面中对该页面的引用（Wiki 链接 `[[页面标题]]` 或 Markdown 链接），在详情页显示。

## 五、任务看板模块

> 路径：`http://localhost:3001/tasks`

任务看板采用三列 Kanban 布局，直观展示任务状态流转。

### 5.1 统计面板

页面顶部显示任务总览：

| 指标 | 说明 |
|------|------|
| 总计 | 所有任务数量 |
| 待办 | `TODO` 状态 |
| 进行中 | `IN_PROGRESS` 状态 |
| 已完成 | `DONE` 状态 |
| 逾期 | 超期未完成的任务数 |

### 5.2 筛选与排序

筛选栏支持：

| 筛选条件 | 选项 |
|----------|------|
| 状态 | 全部 / 待办 / 进行中 / 已完成 |
| 优先级 | 全部 / 紧急 / 高 / 中 / 低 |
| 排序 | 创建时间 / 截止日期 / 优先级 |
| 方向 | ↑ 升序 / ↓ 降序 |

点击 **"清除筛选"** 恢复默认。

### 5.3 看板三列

| 列 | 状态 | 颜色 |
|----|------|------|
| 待办 | TODO | 🟡 黄色 |
| 进行中 | IN_PROGRESS | 🔵 蓝色 |
| 已完成 | DONE | 🟢 绿色 |

**卡片信息：**
- 标题、描述（去除 Markdown 格式后的纯文本）
- 优先级徽章（灰/黄/橙/红）
- 截止日期（逾期显示 ⚠ 警告）
- 逾期任务卡片显示红色边框

**状态流转按钮：**

| 当前列 | 可用操作 |
|--------|---------|
| 待办 | 开始 → 进行中、删除 |
| 进行中 | 完成 → 已完成、回退 → 待办、删除 |
| 已完成 | 重开 → 进行中、删除 |

### 5.4 创建任务

点击 **"新建任务"**：
1. 输入任务标题（必填）
2. 输入描述（可选，支持 Markdown）
3. 选择优先级（低/中/高/紧急），默认"中"
4. 设置截止日期（可选）
5. 点击 **"创建"**

### 5.5 任务详情

点击看板卡片进入详情页：

**页面功能：**
- 状态标签 + 逾期警告（如适用）
- **← 返回看板** 按钮
- 可编辑标题
- 标签管理（添加/移除标签）
- 描述区：**编辑** / **预览** 切换
  - 预览模式使用 Markdown 渲染（白底纸页效果）
- 状态、优先级、截止日期编辑
- 来源链接（如果从便签/知识页转换而来，可点击跳转）
- 保存 / 删除操作

### 5.6 便签转任务

在便签页面点击 ✅，选择的便签将自动创建为任务：
- 任务标题 = 便签第一行
- 任务描述 = 便签内容
- 来源标记为 "便签 #id"

### 5.7 知识页转任务

在知识页编辑页点击 **"转为任务"**：
- 任务标题 = 页面标题
- 任务描述 = 页面完整 Markdown 内容
- 来源标记为 "知识页 #id"
- 页面标签自动复制到任务

## 六、标签管理

标签用于跨模块组织内容，便签、知识页面、任务都可以打标签。

### 6.1 添加标签

在便签/知识页/任务详情页点击 **TagPicker** 组件（标签图标）：
- 从已有标签中选择
- 或输入新标签名创建

### 6.2 管理标签

标签系统提供：
- 数据隔离：每个用户只能看到和管理自己的标签
- 删除标签自动解除所有关联
- 重命名标签

### 6.3 按标签筛选

便签/知识页/任务列表支持 `?tag=id` 参数过滤，只显示含有指定标签的条目。

## 七、全局搜索

> 通过顶部导航栏 🔍 搜索按钮或直接访问搜索功能

### 7.1 搜索范围

支持跨模块搜索：
- 便签内容
- 知识页面标题和内容
- 任务标题和描述
- 标签名称

### 7.2 搜索方式

- 输入关键词后自动搜索
- 结果按类型分组显示（便签 / 知识页 / 任务）
- 每条结果显示标题和匹配片段
- 点击结果跳转到对应详情页

## 八、导入导出

### 8.1 导入文件

在知识页面列表页点击 **"导入"**：
- 支持 `.md` 和 `.txt` 格式
- 可一次选择多个文件
- 文件名自动作为页面标题
- 文件内容作为页面内容

### 8.2 导出文件

在知识页面编辑页底部：
- **导出 .md**：下载 Markdown 格式（保留原始格式）
- **导出 .txt**：下载纯文本格式

---

## 九、文件夹管理

文件夹采用**虚拟路径**方式，无需预先创建。

### 9.1 创建文件夹

将页面移动到新路径时自动创建：
1. 在页面卡片的文件夹下拉框选择 **"+ 新建文件夹..."**
2. 输入路径（如 `工作/项目A`）
3. 系统自动创建对应文件夹

### 9.2 移动页面

在知识页面列表页，使用每张卡片的下拉框直接移动。

### 9.3 层级文件夹

- 支持 `父文件夹/子文件夹` 格式
- 左侧树形面板自动展示层级关系
- 点击 ▶ 展开子文件夹
